### Hi, I'm Will Gwyn

I build open-source tooling for running AI coding agents, and I write [The AIgent](https://theaigent.xyz), a daily newsletter for people building with AI with close to 9,000 subscribers.

#### What I'm working on now

**[aigent-OS](https://github.com/wrg32786/aigent-os)**: Claude Code that refreshes its own context instead of compacting. At a threshold it writes a verified capsule, runs /clear, and resumes in a fresh session. Memory is plain markdown in git, readable with git log. MIT, runs locally, one install (Node 18+). Codex adapter included. Latest stable: [v1.2.0](https://github.com/wrg32786/aigent-os/releases/latest).

**[aigent-talking-head](https://github.com/wrg32786/aigent-talking-head)**: turn one phone clip into a styled talking-head reel with your coding agent. Kinetic captions, titles behind your head, 51 effects, beat-synced music, film finishes and brand presets. Runs locally. Apache-2.0.

**[aigent-design-system](https://github.com/wrg32786/aigent-design-system)**: a design skill for Claude Code, Cursor and Codex that stops generic AI websites. It picks a visual direction, builds it, then checks the result in a real browser.

#### Research

**[governed-agent-organizations](https://github.com/wrg32786/governed-agent-organizations)**: the companion paper and public research corpus on persistent identity, context continuity and human authority in agent organizations. aigent-OS is its reference implementation.
