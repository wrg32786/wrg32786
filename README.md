#### The tools, in the open

**[aigent-OS](https://github.com/wrg32786/aigent-os)**: Claude Code harness and alternative to context compaction. At 80% context it writes a verified capsule, runs /clear and resumes with persistent memory in git. Long-running and multi-agent Claude Code sessions, auto clear instead of auto-compact. MIT, local, Node 18+. Codex adapter. Latest stable: [v1.2.0](https://github.com/wrg32786/aigent-os/releases/latest).

**[aigent-talking-head](https://github.com/wrg32786/aigent-talking-head)**: free, open-source talking-head video editor. Turn one phone clip into a captioned reel for TikTok, Reels and Shorts. 51 effects, 29 motion graphics, 56 transitions, local Whisper captions, kinetic typography and an MCP server. Works with Claude Code, Cursor, Codex and Gemini CLI. Apache-2.0.

**[aigent-design-system](https://github.com/wrg32786/aigent-design-system)**: a design skill for Claude Code, Cursor and Codex that stops generic AI websites. It picks a visual direction, then checks the result in a real browser. See the [live demo](https://tools.theaigent.co/aigent-site-vault).

**[Ultra-web-design](https://github.com/wrg32786/Ultra-web-design)**: frozen. The maintained version is [aigent-design-system](https://github.com/wrg32786/aigent-design-system). This Apache-2.0 Agent Skill remains the source for distinctive, accessible, production-ready business websites.

**[operator-kit](https://github.com/wrg32786/operator-kit)**: 5-agent AI team for Claude Code operators: Iris (design), Lyra (build), Echo (scout), Newton (research), Hypatia (critic). One-command install, context-loading hook included. For the current system, use aigent-OS.
