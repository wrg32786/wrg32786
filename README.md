### Hi, I'm Will Gwyn

I build open-source tooling for running Claude Code as a long-lived agent, and I write [The AIgent](https://theaigent.xyz), a daily newsletter for people building with AI with close to 9,000 subscribers.

#### What I'm working on now

**[aigent-OS](https://github.com/wrg32786/aigent-os)**: Claude Code that refreshes its own context instead of compacting. At a threshold it writes a verified capsule, runs /clear, and resumes in a fresh session. Memory is plain markdown in git, readable with git log. MIT, runs locally, one install (Node 18+). Codex adapter included.

Managed Auto-Refresh is in the v1.1.0-rc.1 pre-release. Evidence and known limits are in the [README](https://github.com/wrg32786/aigent-os#evidence-and-limits).

**[governed-agent-organizations](https://github.com/wrg32786/governed-agent-organizations)**: the companion paper and public research corpus on persistent identity, context continuity and human authority in agent organizations. aigent-OS is its reference implementation.
